Setup

  1. On your Galaxy, open Developer options → Default USB configuration → USB tethering.
  2. Connect the phone to your Mac with a USB data cable.
  3. Your Galaxy provides internet access; your Mac uses that connection.

If the default option is unavailable, enable USB tethering manually after connecting.

The background service starts at boot. No separate Galaxy entry appears in Network Settings.

Apple Silicon, macOS 26+, IPv4. USB debugging is not required. This package is not Developer ID signed or notarized.

Documentation: github.com/ddotz/galaxytethermac
