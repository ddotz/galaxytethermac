설치 안내

  • Apple Silicon arm64 Mac과 macOS 26 이상이 필요합니다.
  • Galaxy 휴대전화에서 USB 테더링을 켠 뒤 USB 케이블로 Mac에 연결하십시오.
  • 설치가 끝나면 Mac 로그인과 휴대전화 연결 시 백그라운드 서비스가 자동으로 연결을 감지합니다.

서비스는 local.galaxy-usb-tether launchd 작업으로 실행됩니다. 구성 파일은 /Library/Application Support/GalaxyUSBTether/config에 설치됩니다.

제거하려면 제품 문서의 제거 절차를 따르십시오.
