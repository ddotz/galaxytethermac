설정 방법

  1. 갤럭시에서 개발자 옵션 → 기본 USB 구성 → USB 테더링을 선택합니다.
  2. 데이터 통신 가능한 USB 케이블로 Mac에 연결합니다.
  3. 갤럭시가 인터넷을 제공하고 Mac이 그 연결을 사용합니다.

기본 USB 구성에 해당 항목이 없으면 연결 후 USB 테더링을 직접 켜세요.

Mac 부팅 시 서비스가 자동 실행됩니다. 네트워크 설정 목록에는 별도 갤럭시 항목이 표시되지 않습니다.

Apple Silicon, macOS 26 이상, IPv4를 지원합니다. USB 디버깅은 필요하지 않습니다. Apple 서명·공증은 받지 않았습니다.
